# 🔒 Proxy de Vídeo com Vercel Rewrites

Solução para esconder a URL original do vídeo usando proxy reverso via CDN da Vercel.

## 📁 Arquivos

- `index.html` → Painel de diagnóstico
- `vercel.json` → Configuração do proxy

## 🚀 Deploy na Vercel

1. Crie uma conta em [vercel.com](https://vercel.com)
2. Instale a CLI: `npm i -g vercel`
3. Na pasta do projeto, execute: `vercel`
4. Siga as instruções (conecte seu GitHub ou faça deploy direto)

**OU** faça deploy arrastando a pasta para [vercel.com/new](https://vercel.com/new)
